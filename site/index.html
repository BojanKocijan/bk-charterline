Theme

For Claude Code and Anthropic's plugins

Get the most out of Claude Code and its plugins

Claude Code and Anthropic's skills give you powerful tools. BK Charterline gives them a way of working: binding rules, a team of agents and hand-offs that decide when each skill runs, what standard it meets, and when to stop for your yes.

curl -fsSL https://raw.githubusercontent.com/BojanKocijan/bk-charterline/main/install.sh | bash

Why add it

It doesn't replace your tools. It makes them work together.

  • Claude Code

    On its own It can do almost anything, so each session picks its own way of working.

    With BK Charterline Every session follows the same 38 laws, in every project.

  • Anthropic's plugins

    On its own Each skill does one job well, but nothing says when to use it.

    With BK Charterline Each stage of the team calls the right skill, and Claude tells you when a useful plugin is missing.

  • Built-in tools

    On its own /code-review, plan mode and worktrees help only if you remember them.

    With BK Charterline The rules run them for you: a review before every pull request, a worktree for every parallel session.

  • Safety

    On its own Good intentions, and an agent that sometimes forgets them.

    With BK Charterline A hook that blocks merges, pushes to main and secrets before they happen.

How they work together

BK Charterline

The rules, the gates and the hand-offs, and the standards every skill's output meets: WCAG 2.2 AA, the design you're given, your chosen library, your merge.

Claude Code

Built-in tools the rules call on: /code-review, plan mode and worktrees.

Anthropic plugins

Specialist skills, one job each. When a job needs one you don't have, Claude asks, gives you the command and carries on with our own skill meanwhile.

  • Design critique+design:accessibility-reviewan accessibility-only audit, held to our WCAG 2.2 AA
  • Deploy steps with undo (Law 35)+engineering:deploy-checklistpre-deploy checks before your ordered steps
  • Research synthesis and the deck+design:user-researchplanning the study before there are transcripts
  • Review gates (Law 37)+/code-reviewClaude Code's review on every change, engineering:code-review on the riskiest

Anthropic's plugins are used when they're installed; every stage works without them. Mapped in TEAM_WORKFLOW §8, Oct 8, 2026.

Install

One command, then every session follows the rules

The script clones BK Charterline to ~/.bk-charterline, adds it to Claude's global memory, registers the hook and links the agents and skills. Open any Claude Code session and it starts with Rules loaded.

curl -fsSL https://raw.githubusercontent.com/BojanKocijan/bk-charterline/main/install.sh | bash
