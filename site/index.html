Install

One command, then every session follows the rules

The script clones BK Charterline to ~/.bk-charterline, adds it to Claude's global memory, registers the hook and links the agents and skills. Open any Claude Code session and it starts with Rules loaded.

curl -fsSL https://raw.githubusercontent.com/BojanKocijan/bk-charterline/main/install.sh | bash
